# 토끼네 자리 🐰

모바일 세로 화면용 HTML5 논리 퍼즐. 각 **색 자리(영역)**·**가로줄**·**세로줄**에
토끼를 한 마리씩 놓되, 토끼끼리는 **대각선을 포함해 어디로도 붙어 앉을 수 없다**.
(Queens / Star-Battle 계열)

## 바로 해보기

- `index.html` 을 브라우저에서 열면 끝. (퍼즐 데이터가 파일 안에 내장돼 있어 서버 없이도 동작)
- 정적 서버로 띄우면 `puzzles.json` 을 먼저 불러오므로, 레벨만 따로 갈아끼울 수 있다.
  ```bash
  python3 -m http.server 8000     # http://localhost:8000
  ```

## GitHub Pages 배포

배포 주소: **https://joon-bot.github.io/meowdoku-game/**

`.github/workflows/deploy-pages.yml` 이 `main` 또는 작업 브랜치에 push 될 때마다
퍼즐을 검증하고 `index.html` + `puzzles.json` 을 게시한다.

### 최초 1회는 수동 설정이 필요하다

워크플로의 `GITHUB_TOKEN` 에는 **Pages 사이트를 생성할 권한이 없다**
(저장소 관리자 권한이 필요하다). 그래서 처음 한 번은 사람이 켜줘야 한다.

1. 레포 **Settings → Pages**
2. **Source** 를 `GitHub Actions` 로 선택

> ⚠️ **이 레포는 비공개(private)다.** 비공개 레포의 Pages 는 **GitHub Pro 이상**에서만 동작한다.
> 무료 플랜이라면 레포를 공개로 바꾸거나 플랜을 올려야 한다.
>
> 그리고 어느 쪽이든 **게시된 페이지 자체는 누구나 접근 가능**하다.
> (접근 제한이 걸린 Pages 는 Enterprise 기능이다.) 레포가 비공개면 소스만 가려질 뿐,
> 게임 URL 은 링크를 아는 사람 누구에게나 열린다.

### Actions 없이 배포하는 방법

워크플로를 쓰지 않고 브랜치에서 바로 게시해도 된다. 게임이 레포 루트에 있고
`.nojekyll` 도 있어서 추가 설정이 필요 없다.

- Settings → Pages → Source: **Deploy from a branch** → 브랜치 선택 → 폴더 `/ (root)`

이 경우 배포 전 퍼즐 검증은 돌지 않는다.

## 힌트

힌트 버튼은 **지금 논리적으로 확정 가능한 다음 한 수**를 이유와 함께 알려준다.
찍기(백트래킹)로 답을 훔쳐보는 게 아니라, 아래 규칙을 순서대로 적용해 사람이 따라갈 수 있는
추론 한 단계를 뽑아낸다.

| 단계 | 규칙 |
| --- | --- |
| T0 | 어떤 영역/줄에 남은 후보가 한 칸뿐 → 그 칸에 토끼 확정 |
| T1 | 한 영역의 후보가 모두 한 줄에 몰림(또는 그 반대) → 나머지 칸 제외 |
| T2 | k개의 줄이 k개의 영역만 나눠 쓰는 경우 (k=2,3) → 나머지 칸 제외 |
| T3 | 그 칸에 놓으면 어떤 영역/줄이 자리를 전부 잃음 → 그 칸 제외 |

플레이어가 **정답이 아닌 칸에 토끼를 놓은 상태**라면 힌트는 먼저 그 칸을 짚어준다.

> 힌트는 현재 무료다. 광고 연동은 `HINT_CONFIG` (index.html) 한 곳만 바꾸면 되도록 분리해 뒀다.
> ```js
> const HINT_CONFIG = { free: true, onConsume() { /* 광고 연동 지점 */ } };
> ```

## 토끼 그림 교체

토끼는 인라인 SVG로 그려져 있고 `RabbitArt` 모듈에 모여 있다. 이미지 에셋으로 바꾸려면:

```js
RabbitArt.mode = 'image';
RabbitArt.images = { rabbit: 'assets/rabbit.png', mark: 'assets/x.png' };
```

게임 로직은 `RabbitArt.html(kind, mood)` 만 호출하므로 그 외에는 손댈 필요가 없다.

## 레벨 다시 만들기

```bash
node tools/generate-puzzles.mjs        # puzzles.json 생성 (레벨 하나 만들 때마다 저장)
node tools/build.mjs                   # 검증 + index.html 내장 사본 갱신
```

생성기는 다음을 **모든 레벨에 대해 보장**한다.

1. 해가 **정확히 하나** — 무작위로 영역을 키운 뒤, 가짜 해가 나오면 칸 하나의 소속 영역을
   바꿔 그 해를 깨뜨리는 수선(repair) 과정을 반복한다. 정답 칸은 절대 옮기지 않으므로
   원래 정답은 항상 유효하게 유지된다.
2. **찍기 없이 논리만으로 풀린다** — 위 T0~T3 규칙으로 끝까지 풀리지 않으면 채택하지 않는다.
   덕분에 힌트가 어느 상황에서도 막히지 않는다.
3. 모든 영역은 **상하좌우로 연결**돼 있고, 크기가 3칸 이상 · 2.2N칸 이하로 균형이 잡혀 있다.

`tools/build.mjs` 는 생성기와 독립적으로 위 조건들을 다시 검사하므로,
`puzzles.json` 을 손으로 고친 경우에도 안전망이 된다.
